# Supermarket Sales & Inventory Management System

## Overview
A comprehensive relational database application built with Microsoft Access to manage day-to-day supermarket operations. Co-developed as a team project, this system streamlines inventory tracking, supplier relations, customer data, and sales processing through an interactive GUI and dynamic queries.

## Key Features
* **Relational Architecture:** Structured 5 core tables (Products, Customers, Suppliers, Sales_Header, Sales_Details) to ensure data integrity and seamless relationships.
* **Inventory Management:** Real-time stock updates based on daily sales and new supplier deliveries.
* **Dynamic Reporting:** Automated calculation of net profits, low stock alerts, and invoice generation.
* **Interactive Dashboards:** User-friendly forms for fast checkout, data entry, and report selection.

## Tech Stack
* **Database & GUI:** Microsoft Access
* **Language:** SQL (Queries & Data Manipulation)
